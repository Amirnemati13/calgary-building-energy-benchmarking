# بنچمارک مصرف انرژی ساختمان‌های کلگری

[English](README.md) · [نوت‌بوک فارسی](notebooks/analysis.fa.ipynb) · [روش پژوهش](docs/methods.fa.md) · [نتایج](reports/RESULTS.fa.md)

ویژگی‌های پایهٔ ساختمان تا چه حد مصرف سالانهٔ انرژی را برای یک ملک جدید، محدودهٔ مکانی دیگر یا سال آینده پیش‌بینی می‌کنند؟

این پروژه با داده‌های عمومی **BenchmarkYYC** به این پرسش می‌پردازد. رگرسیون Ridge و Random Forest با میانهٔ مصرف کاربری و، در صورت وجود سابقه، مصرف سال قبل مقایسه می‌شوند. ارزیابی برای ملک دیده‌نشده، بلوک مکانی کنارگذاشته‌شده و سال بعد جداگانه انجام می‌شود.

## داده و دامنهٔ مطالعه

نسخهٔ مرجع در **۲۴ سپتامبر ۲۰۲۶** دریافت شده و شامل **۲۷۸۱ رکورد ملک–سال برای ۶۵۴ شناسهٔ ملک** در سال‌های **۲۰۱۹ تا ۲۰۲۵** است. یک رکورد فاقد Site EUI است و ۲۷۸۰ رکورد وارد تحلیل می‌شوند. هر شناسهٔ ملک الزاماً معادل یک ساختمان منفرد نیست.

منبع، [برنامهٔ BenchmarkYYC شهرداری کلگری](https://www.calgary.ca/environment/programs/building-energy-benchmarking-program.html) و [نقشهٔ عمومی عملکرد ساختمان‌ها](https://grid.opentech.eco/orgs/calgary/viz) با میزبانی OPEN Technologies است. دادهٔ **۲۰۲۵ در این نسخه موقت** در نظر گرفته شده است. افشای عمومی انتخابی است و مجموعه، سرشماری ساختمان‌های کلگری محسوب نمی‌شود.

مخزن شامل کد تحلیل، نتایج تجمیعی، نمودارها و مشخصات منشأ داده است. رکوردهای خام هنگام اجرا دریافت می‌شوند و وارد کنترل نسخه نمی‌شوند. جزئیات واحدها و انتساب منبع در [راهنمای داده](docs/data-sources.md) آمده است.

## یافته‌های اصلی

مدل‌ها به‌طور یکدست از میانهٔ مصرف همان کاربری بهتر عمل نمی‌کنند. در آزمون ۲۰۲۴، Random Forest اندکی RMSE پایین‌تری دارد، اما MAE آن بیشتر است. برای املاک دارای سابقهٔ سال قبل، مبنای تداوم مصرف به‌مراتب دقیق‌تر از مدل‌های متکی بر ویژگی‌های پایه است.

| ارزیابی | MAE میانهٔ کاربری | MAE مدل Ridge | MAE مدل Random Forest |
|---|---:|---:|---:|
| ملک جدید، ۲۰۱۹ تا ۲۰۲۳ | ۱۰۲٫۸۹ | ۱۰۴٫۶۷ | ۱۰۷٫۰۲ |
| بلوک مکانی، ۲۰۱۹ تا ۲۰۲۳ | ۱۰۵٫۵۴ | ۱۰۴٫۲۵ | ۱۰۹٫۱۹ |
| سال ۲۰۲۴، ۵۵۹ ملک | ۸۵٫۷۷ | ۸۷٫۱۳ | ۸۹٫۷۱ |

واحد MAE، **کیلووات‌ساعت بر مترمربع در سال** است و مقدار کمتر بهتر است. در زیرمجموعهٔ مشترک ۵۴۷ ملک با دادهٔ ۲۰۲۳، خطای مصرف سال قبل **۳۲٫۴۰**، میانهٔ کاربری **۸۴٫۲۳** و Random Forest برابر **۸۸٫۹۶** است. این نتایج به مدل‌های ثابت و نسخهٔ دادهٔ بررسی‌شده مربوط‌اند؛ مقایسهٔ جامع همهٔ الگوریتم‌ها نیستند.

## اجرای تحلیل

از Python **3.12** استفاده کنید. دستورات زیر را از پوشهٔ اصلی مخزن اجرا کنید:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/download_data.py --output data/snapshots/2026-09-24-release
python scripts/run_notebook.py notebooks/analysis.fa.ipynb
```

دریافت‌کننده، نسخهٔ موجود را بازنویسی نمی‌کند. برای دریافت بعدی پوشهٔ تازه‌ای انتخاب کنید و متغیر `BENCHMARKYYC_SNAPSHOT` را روی مسیر مطلق آن قرار دهید. مسیر خروجی با `BENCHMARKYYC_RESULTS` قابل تغییر است؛ مقدار پیش‌فرض `results/local/` است.

برای کار تعاملی، JupyterLab را با `python -m pip install jupyterlab` نصب و نوت‌بوک فارسی یا انگلیسی را باز کنید. کد دو نسخه یکسان است.

داده‌های منبع ممکن است بازنگری شوند؛ دریافت تازه حتی برای همان سال‌ها می‌تواند نتیجهٔ متفاوتی بدهد. هش‌های منشأ را با [`data/reference_manifest.json`](data/reference_manifest.json) مقایسه کنید. این مسیر عمومی آرشیو تغییرناپذیر ارائه نمی‌کند؛ بازتولید دقیق به نگهداری نسخهٔ محلی اصلی وابسته است.

## طراحی پژوهش

- **هدف:** شدت مصرف سالانهٔ انرژی در محل، Site EUI.
- **ورودی‌ها:** کاربری، لگاریتم زیربنا، سال ساخت و سال گزارش.
- **کنترل نشتی:** پیش‌پردازش درون آموزش، حذف شاخص‌های هم‌زمان مصرف و انتشار از ورودی، و جداسازی کامل شناسهٔ ملک در اعتبارسنجی گروهی و مکانی.
- **تفسیر:** Exact SHAP روی ۱۰۰ ملک آزمون ۲۰۲۴ با پس‌زمینهٔ آموزش؛ اهمیت ویژگی، اثر علّی بهسازی نیست.

نسخهٔ تاریخی ممکن است اصلاح شده باشد، بین بلوک‌ها حاشیهٔ حذف وجود ندارد و اطلاعات اشغال، آب‌وهوا، پوسته و تأسیسات کامل نیست. این تحلیل ادعای صرفه‌جویی علّی یا تعمیم به خارج از نمونهٔ کلگری ندارد. جزئیات در [روش و محدودیت‌ها](docs/methods.fa.md) آمده است.
